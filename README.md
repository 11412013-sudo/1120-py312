# 電阻色碼計算器

以電阻色環數字代碼計算電阻值與誤差，支援常見的 4 環與 5 環電阻。

## 環境需求

- Python 3.12 或更新版本
- 不需要安裝額外套件

## 執行方式

在專案根目錄執行：

```powershell
python ".\02色碼計算py"
```

## 色碼對照

| 輸入數字 | 顏色 |
| ---: | :--- |
| 0 | 黑 |
| 1 | 棕 |
| 2 | 紅 |
| 3 | 橙 |
| 4 | 黃 |
| 5 | 綠 |
| 6 | 藍 |
| 7 | 紫 |
| 8 | 灰 |
| 9 | 白 |
| 10 | 金 |
| 11 | 銀 |

`0` 到 `9` 對應有效數字色環及倍率色環；`10`（金）和 `11`（銀）可用於倍率與誤差色環。程式會依色環位置檢查輸入是否有效。

## 輸入格式

依照電阻色環順序輸入 4 個或 5 個數字，數字之間以空格或逗號分隔。每次輸入完成後，程式會顯示阻值與誤差百分比；輸入 `q` 可結束。

### 4 環範例

```text
4 7 2 10
```

代表黃、紫、紅、金，結果為 `4.7 kΩ ±5%`。

### 5 環範例

```text
1 0 0 2 1
```

代表棕、黑、黑、紅、棕，結果為 `10 kΩ ±1%`。

程式會提示錯誤的色碼、色環數量、位置不適用的顏色，以及第一個有效數字為黑色等輸入問題。
